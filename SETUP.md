## 5. Android signing + APK workflow (GitHub Actions)
1. Make the release keystore once and keep it forever (updates must be signed with the same key):
   `keytool -genkeypair -v -keystore j-release.keystore -alias j -keyalg RSA -keysize 2048 -validity 10000`
2. Secrets and variables, in one go: `gh auth login`, `cp scripts/github-secrets.env.example scripts/github-secrets.env`, fill in the keystore path and passwords and the `RELEASES_TOKEN` (a fine-grained PAT with Contents: read and write on `j-releases`), then `bash scripts/github-secrets.sh`. It sets the 15 secrets (`ANDROID_KEYSTORE_BASE64`, the three keystore values, `GOOGLE_SERVICES_JSON` from `android/app/google-services.json`, the public `VITE_*` values, `RELEASES_TOKEN`) and the variables `RELEASES_REPO` and `SITE_URL`. Nothing in that file leaves your PC.
3. Build: push a commit whose message contains `[apk]` or `[release]`. The workflow builds, signs, uploads `J-<version>.apk` to a release in `j-releases` and rewrites `latest.json` (version, versionCode = run number, url, notes). Bump `version` in `package.json` for a new user-facing version.
4. Local debug build: `npm run build && npx cap sync android && cd android && ./gradlew assembleDebug` (needs `android/app/google-services.json` and the Android SDK).

## Staying on the free tiers (checked against the current plan limits)
Supabase Free: 500,000 edge-function calls/month, 500 MB database, 10 GB egress, 2 active projects, pause after 7 idle days, 150 s per function call.
- **Cron is gated.** `tick` runs at most once a minute and only when a signal is about to expire or an iPhone re-ring is due; one call runs four 15-second passes (about 50 s, under the 150 s limit). Idle days cost 0 calls; a busy signal day costs at most 1,440. The scheduler is 720/month, `wann-sync` 2,880/month and only while someone has Wann on. Worst realistic month: under 50,000 calls, a tenth of the quota.
- **Database stays small.** A daily job deletes `push_log` after 14 days, finished re-rings after 2 days, unmatched tracker positions after 60 days, old signal events after 180 days, and pg_cron's run history after 7 days. Signals, receipts and reports are kept; at ~1 KB each, years of signals fit in a few MB.
- **Egress is tiny.** Pushes carry a few hundred bytes; the app's JSON responses are small. Report and promo images are rendered on the phone, never served by Supabase.
- **Pausing.** The hourly scheduler and your own logins are normal API activity; if Supabase emails a pause warning, open the dashboard once.
- **Two free projects.** `J` needs a slot: pause or delete `35Kb`, or move `wann` into a second free organization (free orgs can be created without a card).

GitHub Free: 2,000 Actions minutes/month on private repos, 500 MB artifact storage. The APK job only runs on commits marked `[apk]`/`[release]` (about 8 minutes each), cancels superseded runs, keeps artifacts 7 days, and publishes to the public `j-releases` repo where releases are free and unlimited.

Netlify Free: 300 build minutes and 100 GB bandwidth/month. Only `main` builds; turn off Deploy Previews and branch deploys (Site configuration → Build & deploy → Branches and deploy contexts) so pushes to other branches cost nothing. Firebase Cloud Messaging is free. Resend Free: 3,000 emails/month and 100/day (invites plus login codes).

## Acceptance checklist
Automated here: schema and receipt rules (`supabase/tests/run.sh`), lot math (`npm test`), type-check and build, Android compile. On your phones:
- [ ] Invite → email from your domain → confirm → code login works; a non-invited email is refused.
- [ ] Close and reopen after 7+ days → still signed in (web, installed iPhone app, APK).
- [ ] iPhone, app closed, locked: test signal → banner + sound within 5 s; not opened → re-rings every 30 s until expiry; tap → card opens directly.
- [ ] iPhone, app open: exactly one notification; the card updates live.
- [ ] 10 signals in a row on iPhone → 10 separate alerts, permission still granted.
- [ ] Android, app killed, locked: full-screen call alert with ringtone + vibration until Open/Skip/expiry.
- [ ] Android, unlocked in another app: alert pops over it (overlay granted) or the call-style heads-up keeps ringing.
- [ ] Android Skip and the close-question Yes/No work with the app killed.
- [ ] Card fits without scrolling at 360×640; every copy puts the exact value on the clipboard; lot math matches a hand calculation for XAUUSD and USDJPY.
- [ ] Swipe locked until all four copies or 10 s; swipe → taken; Skip → skipped; never opened → missed at expiry.
- [ ] Tracker EA (investor password) opens a matching position → receipt becomes taken; balance syncs.
- [ ] Follow-ups reach only taken/likely users.
- [ ] EA retry: disconnect internet, open a trade, reconnect → the signal arrives once.
- [ ] Weekly report at Friday 17:00 New York; share image 1080×1350 with the logo; test signals excluded.
- [ ] Removing a user signs them out everywhere and stops their pushes.
- [ ] Block XAU for one user → no XAU signal, follow-up or report line for them.
- [ ] Wann off by default; on → every 85%+ game of the next 7 days in one alert, then each new one; off → nothing more.
- [ ] A Wann call that drops below the rule → withdrawn push; a finished game → Won/Lost and the close question.
- [ ] Admin shares a closed EA call and a Wann call in both formats; Hide levels blurs a live call.
